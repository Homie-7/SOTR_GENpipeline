## Diagnosis (render_s6.py)
- **Timing:** each Wash and Word runs on the OLD clock through TMAP (smoothed, sigma 0.5 s). Its in_dur 3.0 and
  out_dur 3.5 are in old seconds, squeezed 2-2.9x in the battles. So the pop-ups land late or soft, and the exits
  rush at different rates per wall.
- **Burns:** each battle Wash burns with its own PaperBurn on its own t_out (Iéna 53, Eylau 55.5, Friedland 57.5
  old), so Friedland stays full while the others are gone. This is not one front.
- **Flag holes:** in `GenFlag._v6_maps` (line ~866) `my = self.Y`, i.e. SCREEN rows, so T1 (holes, soot, stains)
  rides the cloth sideways (uc) but not vertically. The fleurs use `_vcoord` (cloth rows), so the holes slide
  against the fleurs. Fix: for kind 'fleur' (or for all kinds under RETIME_FR, to keep v14 bit-identical), set
  my = (Y - top)/hgt * bh from `self._vcoord(a_key)`. Note that `_vcoord` needs `self.fl_fidx` set first; set it in
  draw() before `_v6_maps`.
- **Map alpha:** already done by `--v7-alpha` + the ink dissolve (INK0/INK1). Just confirm it in the review.
